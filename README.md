# Smart Planner

Smart Planner — это удобное приложение для управления задачами с интеллектуальной функцией декомпозиции. Проект разработан в рамках учебной работы (10 класс) и позволяет не только создавать и отслеживать задачи, но и разбивать большие цели на выполнимые шаги с помощью искусственного интеллекта.

## 🚀 Возможности

- **Создание и редактирование задач**: Указывайте название, описание, приоритет, дату и время выполнения, устанавливайте напоминания.
- **Календарь**: Наглядное отображение задач на каждый день, быстрая навигация по месяцам.
- **Статистика**: Отслеживайте прогресс: количество выполненных задач, общая продуктивность в процентах.
- **AI-декомпозиция**:
  - Введите большую цель (например, «научиться подтягиваться 30 раз»).
  - Укажите текущий уровень, желаемый результат и время, которое готовы уделять в день.
  - ИИ оценит минимально возможный срок и сгенерирует пошаговое расписание на дни (с учётом перерывов).
  - Вы можете выбрать дату начала и сразу создать все подзадачи в календаре.
- **Современный интерфейс**: Приложение выполнено в стиле минимализма с использованием Kivy, адаптировано под мобильные устройства (Android).

## 🛠 Технологии

- **Язык программирования**: Python 3.11+
- **Графический фреймворк**: Kivy
- **Искусственный интеллект**: Google Gemini API (библиотека `google-genai`)
- **Хранение данных**: локальный JSON-файл в папке пользователя (`~/.smart_planner/tasks.json`)
- **Уведомления**: (отключено для сборки, ранее использовалась библиотека `plyer`)

## 📦 Установка и запуск

### Локально (для разработки и тестирования)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Laajf/smart-planner.git
   cd smart-planner
   ```

2. Создайте виртуальное окружение и активируйте его:
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # для Linux/macOS
   # или venv\Scripts\activate для Windows
   ```

3. Установите зависимости:
   ```bash
   pip install --upgrade pip
   pip install kivy google-genai requests cython==0.29.36
   ```

4. Получите API-ключ Google Gemini:
   - Перейдите в [Google AI Studio](https://aistudio.google.com/apikey).
   - Создайте ключ и вставьте его в файл `utils/ai_utils.py` (переменная `api_key`).

5. Запустите приложение:
   ```bash
   python main.py
   ```

### Сборка APK для Android

Для сборки используется Buildozer. Инструкция:

1. Установите Buildozer и необходимые системные пакеты (для Linux/macOS).
2. Выполните в корне проекта:
   ```bash
   buildozer init
   # отредактируйте buildozer.spec при необходимости
   buildozer android debug
   ```
Готовый APK появится в папке `bin/`.

Также доступна автоматическая сборка через GitHub Actions (см. раздел Actions в репозитории). Файл workflow уже настроен и запускается при каждом пуше.

## 🧠 Использование AI-декомпозиции

1. На главном экране нажмите **НОВАЯ ЗАДАЧА**.
2. В форме создания задачи выберите **РАЗБИТЬ С AI**.
3. Заполните поля:
   - **Цель** (обязательно) — что хотите достичь.
   - **Текущий уровень** и **Желаемый уровень** (опционально, но повышают точность).
   - **Минут в день** — сколько времени готовы уделять.
   - **Желаемый срок** (опционально) — если хотите уложиться в конкретное число дней.
   - **Дата начала** — с какого дня начнётся выполнение плана.
4. Нажмите **СГЕНЕРИРОВАТЬ ПЛАН**. После обработки появится минимальный срок и детальное расписание.
5. Если план устраивает, нажмите **СОЗДАТЬ ЗАДАЧИ В КАЛЕНДАРЕ** — все подзадачи будут добавлены в календарь с указанными датами.

## 📝 Примечания

- Для работы AI-функции требуется интернет-соединение и действительный API-ключ Google.
- Приложение не использует уведомления в собранной версии (из-за проблем с библиотекой `plyer` при сборке), но функциональность создания и просмотра задач полностью сохранена.
- Данные хранятся в файле `~/.smart_planner/tasks.json` (на macOS/Linux) или в аналогичной папке пользователя.
